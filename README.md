# Calculax ⚡
> **Smart Calculators for Students** — Calculate. Understand. Plan.

Calculax is a premium, all-in-one academic and student calculation platform. Built with a high-trust SaaS aesthetic inspired by Notion, Linear, Apple, and Stripe, Calculax enables students to perform essential academic, admission, and productivity calculations with mathematical accuracy and arithmetic transparency.

## ✨ Key Features

### 🎓 Academic Calculators
- **CGPA Calculator (Multi-Semester):** Configure subjects, credit hours, and university grading scales (**HEC Pakistan, Standard 4.0, NUST, FAST-NUCES, LUMS, UET, Punjab University, COMSATS**).
- **Semester GPA Calculator:** Term-focused GPA with quality point breakdowns.
- **Percentage & Marks Calculator:** Bi-directional marks to percentage conversion with letter grade equivalents and board presets (1100, 850, 800, 100).
- **CGPA to Percentage Converter:** Official HEC Pakistan equivalence, AICTE standard, and linear conversions.
- **Weighted Grade & Course Tracker:** Weight assignments, quizzes, midterms, and finals with required target score planning.
- **Required Final Exam Marks:** Calculates marks needed on final exams to reach target overall course percentages.

### 🏥 Admission & Merit Calculators
- **Pakistan MDCAT Aggregate Calculator:** Official PM&DC weighting (50% MDCAT + 40% FSc + 10% Matric) with **UHS Punjab, NUMS Army Medical, SZABMU, Sindh DUHS, KPK KMU** presets & Hafiz-e-Quran (+20 marks) bonus.
- **University Admission Merit Calculator:** Pre-configured admission aggregates for **NUST (NET), FAST-NUCES, UET (ECAT), GIKI, PIEAS, COMSATS (NAT), LUMS, and IBA Karachi** plus customizable multi-track weighting.

### ⏱️ Student Life & General Tools
- **Attendance & Bunk Planner:** Computes attendance %, safe bunk cushion without falling below 75%/80%, and recovery lectures required.
- **Study Time & Exam Countdown:** Schedules daily study hours to complete syllabus before exams with buffer days.
- **Merit Scholarship Calculator:** Calculates tuition fee discount brackets and monetary savings.
- **Age & Eligibility Calculator:** Exact age down to days for PM&DC, PMA, and CSS admission cutoffs.
- **Date Difference & Semester Countdown:** Academic weeks and working study days counter.
- **Academic Scale Converter:** Normalizes marks across 850, 1100, and 100 scales.

### 🛠️ Platform Capabilities
- 🔍 **Spotlight Search (`Ctrl+K` / `⌘K`):** Instant search across all calculators, keywords, and university tags.
- 💾 **100% Private Local History:** Automatically records recent calculations in local storage with 1-click reopen.
- 🖨️ **Print & Export Summary:** Formatted academic report export ready for `.txt` download or browser printing.
- 🌓 **Dark & Light Mode:** Thoughtfully designed color palettes with system theme auto-detection.
- 📱 **Mobile First & Responsive:** Optimized touch targets from 320px mobile screens to large desktop monitors.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/yawarabbassss/calculax.git
cd calculax

# Install dependencies
npm install

# Start development server
npm run dev
```

### Running Tests
```bash
npm test
```

### Production Build
```bash
npm run build
```

## 🔒 Privacy & Security

Calculax operates on a strict zero-data collection architecture. All calculation formulas are executed client-side in your web browser. No grades, names, or exam scores leave your device.
